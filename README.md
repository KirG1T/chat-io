# Chat-IO 💬

A real-time chat application built with React and Node.js.

🌐 **Live Demo:** [chat-io-mv19.onrender.com](https://chat-io-mv19.onrender.com)

> ⏳ Note: The app is hosted on Render's free tier. Please allow 30-60 seconds for the server to wake up on first visit.

## Tech Stack

**Frontend:** React, Zustand, TailwindCSS, DaisyUI, Socket.IO Client  
**Backend:** Node.js, Express, Socket.IO, MongoDB, JWT, Cloudinary

## Features

- 🔐 Authentication with JWT
- 💬 Real-time messaging via WebSockets
- 🟢 Online user presence
- 🖼️ Profile avatar upload
